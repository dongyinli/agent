

## Project Overview

Built with the LangChain framework, this project implements a ReAct (Reasoning + Acting) Agent with integrated RAG (Retrieval-Augmented Generation), multi-tool invocation, and dynamic prompt switching.

The system automatically determines the task type based on the user's intent—knowledge-based Q&A or report generation—and invokes the appropriate tools and knowledge bases to complete the reasoning process.

A Streamlit streaming interface provides a real-time visualization of the Agent's reasoning and execution process, allowing users to observe its tool calls, knowledge retrieval, and intermediate steps as they happen.
